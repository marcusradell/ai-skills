# Test-driven development with ZOMBIES

Write a unit tests test list according to TDD and ZOMBIES for the logic function. Only write test cases for the ZOMB-letters. Don't pay attention to the IE-letters. Ensure that each test and the test list as a whole is as simple as possible. Use given/when/then syntax for the test titles, but make it terse.
Write one automated test at a time, following the red/green/refactor cycle, arrange/act/assert, and writing terse test titles that loosely follows given/when/then syntax.
